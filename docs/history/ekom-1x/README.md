# Registros históricos da EKM 1.x

Estes documentos preservam a governança e o changelog anteriores à adoção do
EKOM 3.2. Eles explicam decisões e execuções passadas, mas não governam novas
atuações.

As fontes vigentes são localizadas por `AGENTS.md` e
`docs/rfc/KNOWLEDGE-MAP.md`. O conteúdo histórico não foi reescrito para
simular conformidade retroativa.
