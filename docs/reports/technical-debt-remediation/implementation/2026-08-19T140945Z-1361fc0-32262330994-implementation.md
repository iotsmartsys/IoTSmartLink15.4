## Decisões locais

- Foram usados tipos constantes privados da fachada para porta e plug; nenhuma capability foi codificada nos behaviors genéricos.
- A costura `SetupHooks` recebeu endpoint e tipo construídos pela mesma configuração entregue ao behavior, permitindo a evidência contratada sem expor o behavior concreto pela API funcional.
- A propagação do estado da bateria usa listener síncrono entre os dois behaviors já compostos, sem criar scheduler, persistência ou lifecycle transversal.
- Marcadores locais delimitam exclusivamente a tabela de eventos do coordenador, evitando confundir constantes auxiliares com tipos alocados.
- A ADR e o header foram adicionados às dependências de reconfiguração do CMake para que o guard também opere em builds incrementais.
- Nenhuma decisão normativa ou arquitetural ausente foi absorvida localmente.
