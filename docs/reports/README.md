# Relatórios EKOM

Relatórios preservam fatos, achados e evidências de uma atuação e não alteram
fontes normativas por autoridade própria.

```text
docs/reports/<mudança>/
├── analysis/
├── implementation/
├── review/
└── validation/
```

Registros concluídos são históricos. Correção factual usa adendo ou novo
relatório relacionado. O Git preserva autoria, diferenças e linhagem.
