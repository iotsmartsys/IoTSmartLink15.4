# Claude Code — adaptador para o EKOM

Este repositório usa [`AGENTS.md`](AGENTS.md) como fonte canônica de instruções
para agentes. Leia-o integralmente antes de investigar, editar ou validar.

Este adaptador não cria regras, papéis ou autoridade paralelos. A ordem deve
identificar capacidade, resultado, recorte e especificação quando aplicável.
Use o roteamento do `AGENTS.md` para carregar as regras comuns do EKOM 3.2 e
somente o perfil correspondente.
